# 2026-08-04

## 全项目架构与代码审查（SystemMonitor）

产出：`ARCHITECTURE_REVIEW.md`（项目根目录）。覆盖能力扩展、性能优化、架构改进、安全健壮性四个维度，逐模块列出问题 + 建议 + 优先级 + 四阶段路线图。

### 已实测验证的关键结论（非纯代码阅读）

- **内存口径错误（P0）**：`SystemStatsC.c:93-95` 用 `active + wired + compressed`，实测 47.0%，而活动监视器口径 `(internal - purgeable) + wired + compressed` 为 62.8%，**低报 15.8 个百分点 / 3.78 GB**。应用右键菜单里就有「打开活动监视器」，用户一对比即穿帮。
- **动画开销（P0）**：`RingView.swift:23` 动画 0.6s，数据周期 1.0s → **每秒 60% 时间在重绘 3 个环**，与 README「空闲 CPU 几乎为 0」矛盾。改成 0.25s + 小变化跳过是全项目性价比最高的优化。
- **强制开机自启（P0）**：`AppDelegate.swift:22-28` 每次启动无条件 `register()`，用户在系统设置关掉后会被悄悄加回。`sfltool dumpbtm` 确认已注册。
- **登录项指向源码目录（P0）**：注册 URL 为 `file:///Users/chenzhengcai/coding/system_monitor/SystemMonitor.app/`，而 `build-app.sh:20` 的 `rm -rf "${APP}"` 每次打包都会删掉它。
- **二进制入库（P0）**：`git ls-files` 确认 `SystemMonitor.app/Contents/MacOS/SystemMonitor` 在版本库中，且**项目无 `.gitignore`**。
- **mach 端口泄漏（P1）**：`mach_host_self()` 每 tick 调 3 次从不 deallocate。自建探针实测 9000 次调用 → 引用 1→9001，线性泄漏确认。但 32 位计数理论需 45 年才溢出，**实际不会崩溃**，属正确性问题非紧急。
- **Swift 6 严格并发 15 处告警**：`-strict-concurrency=complete` 实测。AppDelegate 6 处（含 2 处 SendingRisksDataRace）、StatsCollector 5 处、WidgetPanel 1 处。给 AppDelegate 加 `@MainActor` 可消除大部分。
- **磁盘口径其实是对的**：实测 46.7%，与 `diskutil` Container Free 263.5 GB 一致（APFS 下 `statvfs("/")` 返回容器级空间）。仅未扣除 purgeable。**这点不要误报为 bug。**

### 项目优点（勿在后续重构中破坏）

- C 层 `-Wall -Wextra -Wconversion -Wshadow` **零警告**，`clang --analyze` **零告警**，质量很高。
- `ContentView` / `StatsContent` 拆分是刻意优化：外层只依赖 settings，避免每秒 stats 更新时重建整棵视图树。
- C 层 `tick`（推进）与 `get`（读取）分离是好设计。
- `WidgetPanel.rightMouseDown` + `WidgetHostView.rightMouseDown` 双保险覆盖圆环间隙，是对 SwiftUI 命中测试局限的务实处理。
- `monospacedDigit` + 固定宽度防数字抖动。

### 扩展的前置依赖（重要）

多数扩展会被现有架构绊住，建议先做底座：
- C-4 消除 C 层全局状态 → 解锁菜单栏模式 / 多消费者 / 单元测试
- C-5 statvfs 阻塞保护 → 解锁多挂载点切换
- X-1 配置模型 + 持久化 → 解锁设置窗口 / 阈值告警 / 频率可调
- S-1 StatsSnapshot 值类型 → 解锁历史曲线

最推荐的扩展：历史曲线 sparkline（纯前端，无新 API）、阈值告警、磁盘 I/O 速率（当前最明显的能力缺口 —— 有网速没盘速）。

## 环境注意事项

本机构建 `swift build` 会因审查环境无法嵌套 `sandbox-exec` 而失败，需加 **`--disable-sandbox`**。与项目本身无关，后续在此工作区构建都要带这个参数。

## 已落实的问题修复（commit cacf23b）

用户要求「只修问题、不加新功能」，已落实审查报告中所有问题修复类条目：

- **C-1 内存口径**：改用 `(internal-purgeable)+wired+compressed`，实测 61.91%（旧 51.17%），对齐活动监视器。
- **C-2/C-3 mach 端口泄漏 + 页大小**：`get_host_port()` 缓存 host port（3000 tick 后引用恒定为 2，修复前 9001）；页大小改用 `sysctl hw.pagesize` 缓存，去掉错误 4096 回退。
- **C-6 网络计数器**：接口移除/回绕时显式归零速率。
- **V-1 动画**：时长 0.6s→0.25s，变化 <3% 跳过动画，降低重绘占空比。
- **A-1 开机自启不再流氓**：仅首次运行且未注册时才注册（UserDefaults 记忆），右键菜单新增「开机自启」勾选项双向同步，尊重用户关闭。
- **A-3**：`AppDelegate` 标注 `@MainActor`，消除 6 处主线程隔离告警；`main.swift` 改为 `@MainActor bootstrap()` + `MainActor.assumeIsolated` 启动。
- **S-1/S-3**：`StatsCollector.onTick` 标量提取消除 `mi/di/ni` 引用告警；新增 `stop()` 并在休眠/唤醒时暂停与恢复采集。
- **W-2/W-4**：`WidgetSettings` 持久化 scale；`AppDelegate` 持久化窗口位置（启动时恢复、退出时保存）；删除 `WidgetHostView` 冗余 `override`；`resizeKeepingTopRight` 先强制布局再读 `fittingSize`（W-1）。
- **A-4/B-3**：`print` 改 `os.Logger`；`build-app.sh` 不再吞 codesign 错误（`--deep` 已移除），新增 `--install` 安装到 `/Applications`（修复 A-2 注册路径指向源码目录）。
- **B-1**：新增 `.gitignore`，`git rm --cached` 取消跟踪已入库的 `.app` 二进制。
